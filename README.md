# jlmjr-dev.github.io

My personal portfolio, live at [jlmjr-dev.github.io](https://jlmjr-dev.github.io).

Built with Next.js (App Router, static export), TypeScript and Tailwind CSS. English and Portuguese, dark and light themes, no server required.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Outputs a fully static site to `out/`. Deployed to GitHub Pages via GitHub Actions on every push to `main`.
